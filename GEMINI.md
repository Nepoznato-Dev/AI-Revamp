# Global Gemini CLI and Antigravity Directives

Use this workspace as the source of truth for all projects and machines.

## Engineering
Follow SOLID, KISS, separation of concerns, and DRY. TypeScript uses strict mode with no `any`. Prefer Angular signals, resources, modern control flow, and zoneless change detection. Use current Spring Boot and Java LTS features, virtual threads, Spring AI, declarative HTTP clients, and modern Java idioms.

## MCP operations
Use Context7 for current external documentation, CodeGraph for repository navigation, GitHub MCP for GitHub operations, Memory MCP for persistent knowledge, and Playwright MCP for browser verification. Do not guess external API signatures.

## Context management
DCP gently nudges at about 40% of model context and asks the user before compression. Automatic compaction is disabled; never reintroduce automatic low-threshold compaction plugins.

## Workflow
Never commit directly to `main`. Keep technical files and configuration in English. New documents must use one language throughout. Use the Wayfinder workflow for larger work and implement only one phase per invocation.
