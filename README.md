# Lumusitech AI Workspace

This repository is the source of truth for the OpenCode and Antigravity
workspaces. It contains shared skills, agents, plugins, hooks, MCP
configuration, and cross-platform setup scripts.

## English documentation

- [Workspace guide](docs/en/README.md)
- [OpenCode agent directives](docs/en/AGENTS.md)
- [Gemini CLI and Antigravity directives](docs/en/GEMINI.md)
- [Available skills](skills/README.md)

### Quick start

Run the setup script for your platform:

```sh
./scripts/setup.sh
```

For Windows, run `scripts/setup.cmd` from PowerShell 7 or Command Prompt.
